# Campa USA (concept) x Vesper Commerce: 1-Hour Delivery Mockup

A concept site showing what a Campa US storefront could look like with one-hour delivery (GoPuff + DoorDash as the delivery 3PL) built in. Campa has no US ecommerce store today. campabeverages.com is the India brand site. This is a concept for a partnership discussion with Reliance Consumer Products.

Pages: index.html (home), campa-now.html (on-demand collection), product.html (PDP with 1-hour option), checkout.html (combined shipping + 1-hour delivery).

Font: Manrope for all text. Palette: #141414, white, #FF0000.
